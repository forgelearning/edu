# Religious Studies misconception mapping

Measured baseline: 66 source questions and 216 expanded questions, all on
one-question tags. The map groups philosophical objections, ethical theories
and Buddhist teachings by the distinction a student is likely to confuse.

| Tag | Error grouped |
|---|---|
| `MC-GRS-ARGUMENTS` | Cosmological, teleological and ontological arguments make different logical moves |
| `MC-GRS-PROBLEM-EVIL` | Logical incompatibility, evidential suffering and soul-making are different challenges |
| `MC-GRS-EXPERIENCE-LANGUAGE` | Experience, verification and religious-language theories use different standards |
| `MC-GRS-KANT` | Kantian duty depends on universalising a maxim and treating people as ends |
| `MC-GRS-UTILITARIANISM` | Act, rule, preference and qualitative utility judge outcomes differently |
| `MC-GRS-NATURAL-LAW` | Natural law uses rational purposes and primary precepts, not whatever is natural |
| `MC-GRS-SITUATION-ETHICS` | Situation ethics applies agape to context rather than absolute rules |
| `MC-GRS-META-ETHICS` | Emotivism, naturalistic fallacy and moral realism answer different questions |
| `MC-GRS-RESPONSIBILITY` | Free will, responsibility and ethical evaluation require distinct judgements |
| `MC-GRS-BUDDHIST-FOUNDATIONS` | Dukkha, anatta, karma and the path are connected but distinct teachings |
| `MC-GRS-BUDDHIST-PRACTICE` | Buddhist communities, stories, devotion and compassion are different practices |

Every tag has a human-readable label and a commit-before-reveal starter.
Result: 11 shared tags, no singletons, 0% mechanical tags.
