# Media misconception mapping

Measured baseline: 50 source questions and 200 expanded questions, all on
one-question tags. The map separates audience models, representation,
semiotics, industry structure, digital participation and regulation.

| Tag | Error grouped |
|---|---|
| `MC-GMEDIA-AUDIENCE-ACTIVITY` | Hypodermic, active-audience, cultivation and two-step-flow claims differ |
| `MC-GMEDIA-REPRESENTATION-GENDER` | Representation constructs meaning and gendered power rather than mirroring reality |
| `MC-GMEDIA-OWNERSHIP-POWER` | Ownership concentration affects power and diversity through gatekeeping |
| `MC-GMEDIA-REGULATION-CONVERGENCE` | Digital convergence creates regulation problems unlike broadcast standards |
| `MC-GMEDIA-SEMIOTICS` | Denotation, anchorage, signs and mode of address organise meaning differently |
| `MC-GMEDIA-LANGUAGE-FORM` | Genre, lighting, close-up and narrative structure are different choices |
| `MC-GMEDIA-INDUSTRY-STRUCTURE` | Institutions, integration, PSB, synergy and convergence describe different relationships |
| `MC-GMEDIA-CULTURAL-INDUSTRIES` | Cultural discount and globalisation affect how media travels between markets |
| `MC-GMEDIA-DIGITAL-PARTICIPATION` | Gatekeeping, algorithms and UGC redistribute production power differently |
| `MC-GMEDIA-AUDIENCE-MEASUREMENT` | Demographics, niches, fragmentation, ratings and targets measure different things |

Every tag has a label and a commit-before-reveal starter. Result: 10 shared
tags, no singletons, 0% mechanical tags.
