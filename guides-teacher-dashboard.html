What the dashboard is for

The teacher dashboard turns student responses into a teaching signal. It does not replace marking or professional judgement: use the class patterns to decide which explanation, example or intervention is needed next.

Sign in and choose a class

Open Teacher sign in. After signing in, choose an existing class or create one. A class has a name, subject, exam board and shareable class code. Students join from the student quiz flow using that code and a display name.

Classes

Creating and managing classes

  1. Choose Create a class and select the subject and exam board.
  2. Share the generated class code with students; no student email address is required for class-linked use.
  3. Open the class to view responses, students, assignments, Spec Points and corrective starters.
Display names: students enter at least a first name and surname, and Forge preserves the complete entered name in teacher views and, for class-linked students, the class-only leaderboard. Teachers can rename a student from the class overview if needed.
Assignments

Set focused practice

Open Assignments, enter a clear title, choose one or more banks and set a due date. The selected banks define the questions counted for completion. Students see the assignment in their Assigned area and on the relevant quiz flow.

Interpret progress correctly

The class card shows completed students, started/in-progress students, students who have not started, answered-question progress and accuracy. A student's accuracy is calculated from questions answered; it is not the same as completion.

Use Completed for every counted question answered, In progress for at least one response without completion, and Not started when no response has been recorded. Past-due assignments remain in the record but stop appearing as active student work.

Reading the dashboard

Misconception heatmap

The heatmap ranks misconception tags by how often they appear in incorrect responses. The tag is the stable identifier; where available, a plain-English descriptor explains the pattern. A raw code does not mean the response is unusable, but it may indicate that the descriptor registry still needs expanding.

Class overview and drill-down

The class overview separates accuracy, participation and assignment completion. Select a student to inspect their misconception profile and re-forge history. Treat small samples cautiously: a percentage based on one or two answers is not a secure judgement.

Corrective starters

Forge can generate a short warm-up from the class's highest-frequency misconceptions. Review the wording and adapt it to your lesson, especially where a tag has no human-readable descriptor yet.

Spec Points

Use specification-level evidence

The Spec Points tab groups logged responses against the mapped exam-board specification points and sorts weaker areas first. Only points with responses after the current tracking update appear, so an absent point does not prove that a class has mastered it.

School Overview

Cross-class planning

School Overview is a read-only view for wider planning. It summarises subjects, classes, engagement, accuracy, misconception frequency and Spec Points without exposing individual student names.
