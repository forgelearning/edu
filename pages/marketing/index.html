For teachers.

Students practise on their own; you see where the class’s thinking breaks down.

  • Set work from any topic, with due dates and progress for every student.
  • See the misconceptions behind wrong answers across the class, with a starter to reteach each one.
  • Class Challenge: students answer the same questions at home and see how the class answered.
  • Class Mode puts questions and the class’s results on the board, with no student devices.
  • A weekly class league only classmates can see, showing first names and initials. Switch it off at any time.
