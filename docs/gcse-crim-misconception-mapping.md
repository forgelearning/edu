# A-Level Criminology misconception mapping

The four Criminology banks contain 200 questions. Before this pass every
question used a single-use bank-position tag; they now use 30 shared
`MC-GCRIM-*` categories, with 0 single-use and 0 mechanical tags. Every
category has a label and a commit-before-reveal starter.

The organising principle is the error that makes neighbouring definitions or
processes easy to swap: crime versus deviance, official versus hidden crime,
theory mechanisms, evidence integrity, punishment aims and justice criteria.
The map keeps forensic methods separate from witness evidence, and legitimacy
separate from effectiveness, because those distinctions change the corrective
teaching move.
