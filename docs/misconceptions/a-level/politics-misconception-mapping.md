# A-Level Politics misconception mapping

The four Politics banks contain 200 questions. Before this pass every question
had a single-use bank-position tag; they now use 28 shared `MC-GPOL-*`
categories, with 0 single-use and 0 mechanical tags. Each category has an
error-focused label and an explicit commit-before-reveal starter.

The organising principle is the distinction students commonly collapse:
participation versus representation, electoral systems versus seat types,
constitutional powers versus institutions, rights tests versus interpretation,
and participation mechanisms versus political outcomes. UK and US examples
remain recognisable while the tags name the underlying error rather than the
country or bank.
